EchoAgent XR 就绪检测

去 Panel 巨幕

打开 Panel（HTTPS） 下载根证书（可选）
  1. 点「打开 Panel」如再弹证书警告：高级 → 继续前往（本机自签开发证书，属预期）。
  2. Panel 打开后：地址栏「作为独立应用打开/运行」→ 独立窗口（免安装）。
  3. 点顶栏「全屏」→ 铺满视野；控制器射线 = 鼠标，蓝牙键盘可输入。
  4. （可选）装了根证书可减少警告：设置 → 安全/加密与凭据 → 安装证书 → CA 证书。 若浏览器不信任用户证书，继续用「继续前往」即可，不影响 WebXR。

无需 adb。本页主要用途：① 判定当前地址是否安全上下文（WebXR 的前提）； ② 一键试启 immersive-vr 会话验证全链路；③ 检测结果自动回传 PC（reports.log）。
若本页在 http:// 下显示 isSecureContext=false： 换 https:// 入口（首次点「继续前往」），或用 pico://flags 把本地址 加入「Insecure origins treated as secure」（PICO OS 5.x 可用）。
